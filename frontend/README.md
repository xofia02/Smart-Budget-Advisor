# Frontend — Smart Budget Advisor

React 19 + Vite + TypeScript. Consome a API em `http://localhost:8080` (JWT no header `Authorization` e renovação em `X-Token-Renovado`).

```bash
npm install
npm run dev
```

Ajuste `VITE_API_URL` em `.env` se o backend não estiver na 8080. Suba o Java **antes** de usar login, viagens e IA.

Contas demo: `ana@demo.com` / `demo12345` (viajante) e `admin@smartbudget.com` / `admin12345`.
